# Big Fireball

A big fireball you shoot, made with one vanilla command. No mods, no data pack.

```
/summon fireball ^ ^1.5 ^3 {ExplosionPower:6b}
```

A big fireball appears in the air right in front of you and floats there.
Punch it and it flies wherever you're looking, then blows up when it hits
something.

The number in `ExplosionPower:6b` is how big the boom is. A ghast's fireball
is `1b`, TNT is about `4b`. Make it bigger or smaller — just keep the `b` on
the end.

You need cheats (or op on a server) to run `/summon`. Works in Minecraft Java
1.21.11 and 26.x.
